# Design System - JuntAe

**Estética:** Institutional Fintech (Inspirado no BTG Pactual).
**Objetivo:** Transmitir estabilidade, segurança e precisão.

## 🎨 Paleta de Cores

| Elemento | Cor | Hex |
| :--- | :--- | :--- |
| **Background Principal** | Preto Absoluto / Azul Noturno | `#000000` / `#0A1128` |
| **Background Cards** | Azul Escuro Institucional | `#101C38` |
| **Ação / Primária** | Azul Royal / Safira | `#0052CC` |
| **Texto (Dark)** | Branco Puro | `#FFFFFF` |
| **Texto (Light)** | Preto / Azul Marinho | `#111111` |
| **Alertas** | Laranja Queimado | `#FF6B00` |

## Typography

- **UI Geral:** `Inter` ou `SF Pro Display`. Foco em clareza corporativa.
- **Dados Sensíveis:** `JetBrains Mono`. Usado para valores monetários (R$), chaves PIX e códigos de transação.

## 🧱 Componentes

- **Bordas:** Cantos retos ou curvatura mínima (`rounded-md` ou `rounded-sm`).
- **Sombras:** Sutis e precisas. Sem efeitos de neon ou glow.
- **Botões:** Tipografia semibold. Estado de loading obrigatório em ações financeiras.
