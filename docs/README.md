# JuntAe - Institutional Fintech Escrow

O **JuntAe** é um WebApp Mobile-First focado em intermediação financeira, apostas entre pares (P2P) e contas garantia (escrow) via PIX. O objetivo é oferecer um ambiente seguro e profissional para que usuários possam criar grupos de apostas ou vaquinhas com a confiança de uma custódia institucional.

## 🚀 Stack Tecnológica

- **Frontend:** React + Vite + Tailwind CSS (Mobile-First)
- **Backend:** NestJS (Arquitetura modular e tipagem forte)
- **Database:** PostgreSQL (via Supabase)
- **Infra:** Vercel (Frontend) & Supabase (Auth & Realtime)
- **Pagamentos:** API de Gateway (Mercado Pago / Banking as a Service)
